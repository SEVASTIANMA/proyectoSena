# ¿ que es la RAM ?

(Memoria de acceso aleatorio) es un tipo de memoria que utilizan las computadoras, celulares, tabletas y otros dispositivos para guardar temporalmente los datos y programas que están siendo utilizados.

**A diferencia del almacenamiento (SSD o disco duro), la RAM es temporal: cuando apagas el dispositivo, la información que estaba en la RAM se pierde.**

**Por ejemplo, cuando abres un videojuego, un navegador y varias aplicaciones al mismo tiempo, esos programas utilizan RAM para funcionar rápidamente.**

**Un ejemplo sencillo**

Imagina que tu computadora es un estudiante:

* SSD/disco duro: es como su mochila, donde guarda todos sus libros.
* RAM: es como el escritorio donde coloca los libros que está utilizando.
* Procesador (CPU): es el estudiante que trabaja con esos libros.
  **Cuanto más grande sea el escritorio, más cosas pueden tener abiertas y utilizar al mismo tiempo**

# Beneficios de la memoria RAM

* Mayor velocidad
* La RAM permite que el procesador acceda rápidamente a los datos que necesita. Esto ayuda a que los programas funcionen con mayor fluidez.
* Permite realizar varias tareas

**Una computadora con suficiente RAM puede tener abiertas simultáneamente:**

* Navegadores.
* Word o Excel.
* Música.
* programas de edición.
* Videojuegos.
* Aplicaciones de comunicación.

**Por ejemplo, tener 16 GB de RAM generalmente permite realizar muchas tareas simultáneamente con mayor comodidad que tener 4 GB.**

*Ayuda en programas exigentes*

**Los programas de edición de vídeo, diseño 3D, fotografía, programación y máquinas virtuales pueden necesitar bastante RAM.**

* Reducir la necesidad de utilizar almacenamiento como memoria

**Cuando falta RAM, el sistema operativo puede utilizar parte del SSD o disco duro como memoria virtual. Como el almacenamiento suele ser más lento que la RAM, tener suficiente RAM puede mejorar la fluidez**

# Desventajas de la memoria RAM

* Es una memoria temporal

**La RAM pierde su información cuando se apaga el dispositivo.**

**Por ejemplo, si estás escribiendo un documento y el equipo se apaga antes de guardarlo, podrías perder el trabajo que no se haya guardado.**

* Tiene un costo

**Aumentar la cantidad de RAM puede requerir comprar módulos nuevos, especialmente en computadoras antiguas o equipos donde la RAM está vendida**

* No siempre más RAM significa más velocidad

**Tener 32 GB de RAM no hace automáticamente que una computadora sea el doble de rápida que una con 16 GB.**

# Tipos de memoria RAM

**Existen diferentes generaciones y formatos.**

* DDR3

**Es una generación antigua que todavía puede encontrarse en computadoras viejas.**

* DDR4

**Ha sido muy utilizado en computadoras de escritorio y portátiles durante muchos años y ofrece un buen equilibrio entre precio y rendimiento.**

* DDR5

**Es una generación más moderna que ofrece mayores velocidades y otras mejoras respecto a DDR4. Se encuentra en muchas computadoras modernas.**

# RAM y velocidad

**La RAM no se caracteriza solamente por la cantidad de GB.**

También existen características como:

* Velocidad: normalmente expresada en MT/s en las generaciones modernas.
* Latencia: cuánto indica que tarda la memoria en responder a determinadas operaciones.
* Canales: por ejemplo, utilizar dos módulos compatibles puede permitir el funcionamiento en doble canal, aumentando el ancho de banda disponible.
* Capacidad: 8GB, 16GB, 32GB, etc.

# En resumen

**La memoria RAM es fundamental para el rendimiento de un dispositivo porque permite que el procesador trabaje rápidamente con los datos de los programas que están en uso.**

Sus principales beneficios:

* Mejora la fluidez.
* Permite realizar varias tareas.
* Puede mejorar la experiencia en juegos.
* Ayuda con programas exigentes.
* Es mucho más rápido que utilizar el almacenamiento como memoria virtual.

# Sus principales desventajas:

**Es temporal.**

* Aumentarla puede tener un costo.
* Más RAM no siempre significa más rendimiento.
* Existen limitaciones de compatibilidad
